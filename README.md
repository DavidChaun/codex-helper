# Codex Helper

Codex Helper 是一个 macOS 菜单栏工具，用于查看 Codex 配额、管理 OpenCodex，并提供本地 WorkBuddy Chat Completions 代理。

## 安装

1. 从 [Releases](https://github.com/DavidChaun/codex-helper/releases/latest) 下载最新 ZIP。
2. 解压后将 `Codex Helper.app` 移到“应用程序”。
3. 首次启动若被 macOS 拦截，请在“系统设置 → 隐私与安全性”中允许打开。

从 1.7.0 开始，应用通过 Sparkle 自动检查和安装后续更新。

## 系统要求

- macOS 15 或更高版本
- Codex、OpenCodex 和 WorkBuddy 功能按需安装

此仓库仅用于发布安装包和自动更新订阅，不包含应用源码。
